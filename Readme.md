# 📘 User Manager — Flask + MySQL CRUD Application

A simple **User Management Web App** built using **Flask**, **MySQL**, and **Docker**.  
This application demonstrates backend development skills such as:

- User creation
- Viewing all users
- Viewing individual user details
- Database integration
- Template rendering with Jinja2

This project was completed as part of an assigned backend task.

---

## 🚀 Features

- ✔️ Flask backend  
- ✔️ Dockerized MySQL database  
- ✔️ Add User  
- ✔️ List Users  
- ✔️ User Details Page  
- ✔️ Clean & Modular Code  
- ✔️ Jinja2 HTML Templates  

---

## 🛠️ Tech Stack

| Component | Technology |
|----------|------------|
| Backend  | Flask (Python) |
| Database | MySQL (Docker) |
| Driver | mysql-connector-python |
| Templates | HTML |

📦 Installing Dependencies

Activate your virtual environment:

source venv/bin/activate


Install required packages:

pip install flask mysql-connector-python
